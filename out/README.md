# Output Folder

Top-level files in this folder are the curated deliverables for the manuscript response.

## Final deliverables

- `coauthor_response_review.md`: main English response with interpretation.
- `tested_vs_not_tested_baseline.csv`: mutually exclusive baseline comparison.
- `tested_outcome_prevalence.csv`: prevalence among tested patients only.
- `selected_threshold_confusion_audit.csv`: TP/FP/TN/FN summary at selected thresholds.
- `score_clinical_utility_summary.csv`: tests avoided and missed diagnoses per 1,000 tested patients.
- `temporal_validation_summary.csv`: temporal holdout summary, including APS.
- `calibration_summary.csv`: binned calibration points.
- `calibration_model_summary.csv`: compact calibration error summary.
- `calibration_overview.html`: interactive calibration figure.

## Archive

Historical experiment folders and intermediate exports were moved to `archive/` to keep the top level focused.
